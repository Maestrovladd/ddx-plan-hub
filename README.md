# План: попа · руки · 1550 ккал · DDX Федосеевский

Личный HTML-хаб: тренировки, питание, меню на неделю.

## Открыть сайт

После деплоя GitHub Pages ссылка будет в описании репозитория.

Локально:

```bash
open index.html
```

## Вкладки

1. **Старт** — вступление и выводы  
2. **Почему плато** — диагноз  
3. **Тренировки** — дни 1 / 2 / 4  
4. **Питание** — 1500–1600 ккал  
5. **Меню** — 7 дней + рецепты  
6. **Консилиум** — сверка и чеклист  

## Не для публичного маркетинга

Личный план. Не медицинская консультация.
